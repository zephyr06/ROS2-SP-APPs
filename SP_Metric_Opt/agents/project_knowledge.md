Priority value conventions:
- smaller values imply higher priority
- earlier position imply higher priority than later position (small index)

Follow Test-Driven Development:
- First add test cases and make sure the tests fail based on existing code
- Then work on fixes to make tests pass
- Run code refactor to improve code readability, and encapsulate individual logic into function calls (but don't overkill this)

Git history management:
- create one commit for each small and functional change each time. one task can have multiple commits. Don't create commit before user review.

User involvement:
- one task is completed only after user approves it. Work on one single task each time.
